# KINETIC Member Mobile App (React Native Expo)

Aplikasi mobile native untuk member gym KINETIC (Android & iOS) dengan Dynamic 15s QR Access Pass dan kontrol kecerahan layar otomatis.

---

## 🚀 Cara Menjalankan Aplikasi Mobile

1. **Masuk ke folder mobile**:
   ```bash
   cd mobile
   ```
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Mulai Expo Server**:
   ```bash
   npm start
   ```
4. **Buka di HP Fisik**:
   - Buka aplikasi **Expo Go** di HP Android / iPhone Anda.
   - Scan QR code yang muncul di terminal terminal untuk langsung mencoba aplikasi di HP Anda!
